# Submission checklist

Deadline: **Mon Nov 9, 2026, 5:00 PM EST**.

## Setup
- [ ] Lens Studio installed (5.22 or newer) and signed in with a Snap/SPECS account
- [ ] Node.js and Git installed
- [ ] SPECS project created from Base Template, `.esproj` at the repo root
- [ ] CLAD plugin installed (`ls-clad@ls-extensions`)
- [ ] Skill pack installed (`npx skills add challengepost/learn-specs --all -y`)
- [ ] Registered for the Live Build Session (Oct 22, 12 PM ET)

## Plan
- [ ] Ran `plan-lens` and approved `devpost/design-brief.md` (`status: approved`)
- [ ] Done criteria are checkable in the preview

## Build
- [ ] CLAD built the Lens from the brief
- [ ] LEAF tests written and run for each done criterion
- [ ] Judged it in Interactive Preview using the brief's "After the build" steps
- [ ] Iterated with design notes and re-ran tests
- [ ] Optional: brought the work in progress to the Live Project Review (Nov 5, 12 PM ET)

## Submit
- [ ] Demo video under 3 minutes, showing the Lens working in preview
- [ ] Video set to **Public** on YouTube
- [ ] Repo is **public** and includes the Lens Studio project and `devpost/`
- [ ] README filled in: problem, audience, why it matters, how CLAD and the MCP were used
- [ ] Devpost submission form completed with the video and repo links
